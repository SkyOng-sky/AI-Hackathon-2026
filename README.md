# ByteForge: An Intelligent AI-Driven PC Sales Engineering

ByteForge is an automated, responsive PC configuration engine engineered for custom computer hardware retailers. The platform leverages an asynchronous Large Language Model framework to interpret unstructured human consultation parameters and map them directly into rule-validated system builds, hyper-localized Malaysian shipping fees, and explicit budget optimizations.

This production framework utilizes real-time streaming network pipelines (`aiohttp` + `asyncio`) bound directly to the high-capacity **google/gemma-4-31B-turbo-TEE** architecture hosted over serverless decentralized networks via Chutes AI.

## 💻 System Deployment & Initialization Guidelines

Follow this sequential, step-by-step technical routine to isolate your workspace dependencies and deploy the interactive builder platform locally.

### Step 1: Source Acquisition
Download the core script execution file `Chutes_AI.py` directly from this repository and save it cleanly into an isolated local folder on your storage drive.

### Step 2: Initialize Your Terminal Console
Launch a standard Windows Command Prompt (`cmd.exe`) window. 

### Step 3: Navigate to Your Workspace Directory
Execute a change directory command to point your current terminal process to the exact path where you saved the `Chutes_AI.py` file:
```cmd
C:\> cd C:\Path\To\Your\Extracted\Project\Folder
```
### Step 4: Isolate the Python Runtime Sandbox
Construct an independent virtual workspace ecosystem (.venv) to insulate your environment libraries from conflicting system dependencies, then trigger its activation script.
```cmd
C:\ProjectFolder> python -m venv .venv
C:\ProjectFolder> .venv\Scripts\activate
```

### Step 5: Install Architecture Dependency Modules
With your terminal successfully bound to the active virtual sandbox ecosystem, execute a bulk collection pull to install the foundational asynchronous and interface tracking packages.
```cmd
(.venv) C:\ProjectFolder> pip install streamlit aiohttp
```

### Step 6: Deploy the Live Cloud Pipeline Runtime
Launch the background orchestration engine and initialize the browser user interface by invoking the Streamlit pipeline execution script
```cmd
(.venv) C:\ProjectFolder> python -m streamlit run Chutes_AI.py
```
